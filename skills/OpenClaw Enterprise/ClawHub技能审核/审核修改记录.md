# ClawHub技能审核修改记录

## 审核日期
2026-04-19

## 审核目的
解除三个已发布技能的"suspicious"标记

## 问题分析

### 根本原因
ClawHub安全扫描器比较SKILL.md内容与registry摘要时发现：
- `Required env vars: none`
- `Primary credential: none`
- `Homepage: none`

但技能实际需要API密钥才能运行，导致被标记为"suspicious"。

### 修复方案
在SKILL.md的YAML frontmatter中添加完整的`metadata.openclaw`声明，包括：
1. `homepage` - 技能主页URL
2. `primaryEnv` - 主凭证环境变量
3. `requires.env` - 所有需要的环境变量
4. `requires.bins` - 需要的CLI工具
5. `apis` - 所有调用的外部API及用途

## 修改详情

### 1. OpenClaw Enterprise (openclaw-enterprise)

**版本**: 1.0.0 → 1.0.1

**新增声明**:
```yaml
homepage: https://openclaw.ai
metadata:
  openclaw:
    homepage: https://openclaw.ai
    primaryEnv: OPENAI_API_KEY
    requires:
      env:
        - OPENAI_API_KEY
        - ANTHROPIC_API_KEY
      bins:
        - python3
        - pip
        - curl
    apis:
      - name: OpenAI API
        url: https://api.openai.com
        purpose: "LLM大语言模型调用，用于Agent推理和内容生成"
        auth: Bearer Token (OPENAI_API_KEY)
      - name: Anthropic API
        url: https://api.anthropic.com
        purpose: "Claude大语言模型调用，用于高级推理任务"
        auth: Bearer Token (ANTHROPIC_API_KEY)
      - name: Enterprise APIs
        url: https://api.openclaw.ai
        purpose: "企业数据源集成（可选，需企业版）"
        auth: API Key
```
