# 产业互联网硅基军团

面向制造业的AI运营平台，一个幕僚长 + 20个专业Agent，覆盖采购/生产/研发/销售/财务/合规全链路。

## 快速启动

```bash
cd industrial-silicon-army
pip install -r requirements.txt
python api_server.py
# → http://localhost:8080
```

## 行业版本
- v1.0 LookingPlas（塑化行业）
- 后续扩展：模具行业 / 化工行业 / 汽车零部件

## 核心Agent

20个专业Agent，幕僚长统一调度，支持自然语言指挥。
