# 反检测对抗指南

## 常见反爬手段及对策

| 反爬手段 | 触发特征 | 对策 |
|---------|---------|------|
| IP限流 | 429/503 | 代理轮换+降频 |
| UA检测 | 403 | UA轮换+浏览器指纹 |
| Cookie验证 | 302跳转登录 | Cookie持久化 |
| JS加密 | 签名参数 | Playwright渲染 |
| 验证码 | 页面弹窗 | 暂停+人工/降低频率 |
| 行为分析 | 异常操作模式 | 模拟人类操作间隔 |

## 小红书特有反爬

- API接口需要签名参数(x-s, x-t)
- 搜索结果需要登录Cookie
- 频繁请求触发滑块验证码
- 建议使用Playwright + 登录态
