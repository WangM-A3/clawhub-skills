# 外贸硅基军团 - 最佳实践指南

> 本文档为外贸硅基军团Skill的使用提供最佳实践参考，涵盖建站、GEO优化、多渠道获客等核心场景。

## 一、WordPress建站最佳实践

### 1.1 站点规划

```
建站前必做清单：
✅ 明确目标市场和受众（欧美/东南亚/中东）
✅ 选定核心产品线（3-5个主打品类）
✅ 确定品牌名称和视觉风格
✅ 准备基础内容（中英文至少）
```

### 1.2 SEO基础配置

| 配置项 | 建议值 | 优先级 |
|--------|--------|--------|
| 页面标题 | `{产品名} - {品牌名}` ≤60字符 | 🔴 高 |
| Meta描述 | `{价值主张} + {CTA}` ≤155字符 | 🔴 高 |
| URL结构 | `/category/product-name` 静态结构 | 🔴 高 |
| 图片ALT | `{产品名} wholesale {规格}` | 🟡 中 |
| 内链策略 | 每篇文章3-5个相关内链 | 🟡 中 |
| 加载速度 | <2秒（目标），<3秒（底线） | 🔴 高 |

### 1.3 页面结构推荐

```
首页结构（外贸B2B）：
├── Hero区域：品牌标语 + 核心产品展示 + CTA
├── 产品分类快捷入口
├── 工厂/公司实力展示（认证、产能、交期）
├── 客户案例 / 成功故事
├── 常见FAQ
└── 联系方式 / 询价表单

产品页结构：
├── 产品名称 + 型号
├── 高质量图片（白底+场景图）
├── 规格参数表
├── 价格区间（面议 or FOB报价）
├── 最小起订量（MOQ）
├── 交货周期
├── FAQ Schema（推荐添加）
└── 关联产品推荐
```

### 1.4 多语言策略

- 首选英语站（全球通用）
- 第二市场：西班牙语（拉美）、阿拉伯语（中东）
- 避免机械翻译，使用本地化内容
- 每种语言使用独立URL（`/es/`, `/ar/`）

## 二、GEO优化最佳实践

### 2.1 AI搜索引擎引用机制

AI搜索引擎（如ChatGPT）引用来源主要来自：
1. **抓取网页内容**（用于训练和实时查询）
2. **提交到权威平台**（Wikipedia、Crunchbase、G2）
3. **新闻稿和媒体引用**
4. **LinkedIn/行业社区内容**

### 2.2 内容质量评分

AI平台评估内容质量的维度：

| 维度 | 权重 | 说明 |
|------|------|------|
| 权威性 | 30% | 域名年龄、外链数量、.gov/.edu引用 |
| 新鲜度 | 20% | 内容更新频率（建议每周更新） |
| 结构化 | 20% | Schema标记、FAQ、H标签层级 |
| 完整性 | 15% | 回答问题的全面程度 |
| 可信度 | 15% | 数据来源标注、避免夸大 |

### 2.3 GEO优化四步法

```
Step 1: 诊断
  → 运行 geo_optimizer.py diagnose 获取当前分数
  → 识别被引用和未被引用的关键词

Step 2: 内容建设
  → 创建深度指南（1500-3000字）
  → 添加FAQ Schema（3-5个问题）
  → 添加HowTo Schema（操作步骤）

Step 3: 权威背书
  → 提交Wikipedia条目
  → 在Crunchbase/LinkedIn建立公司档案
  → 发布新闻稿到PR Newswire/Business Wire

Step 4: 持续监控
  → 每月运行一次优化
  → 跟踪竞品被引用情况
  → A/B测试不同内容策略
```

### 2.4 Schema标记推荐

必须添加的Schema类型：

```json
// Organization Schema（首页）
{
  "@type": "Organization",
  "name": "Your Brand",
  "url": "https://yoursite.com",
  "description": "...",
  "knowsAbout": ["keyword1", "keyword2"]
}

// FAQ Schema（产品页/FAQ页）
{
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is your MOQ?",
      "acceptedAnswer": { "@type": "Answer", "text": "Our MOQ is 500 units..." }
    }
  ]
}

// Product Schema（产品页）
{
  "@type": "Product",
  "name": "Product Name",
  "brand": "Brand Name",
  "offers": {
    "@type": "Offer",
    "priceCurrency": "USD",
    "availability": "https://schema.org/InStock"
  }
}
```

## 三、Shopify建站最佳实践

### 3.1 店铺初始化检查清单

```
店铺设置：
□ 商店名称和描述（包含核心关键词）
□ 联系信息（邮箱、电话、地址）
□ 时区和货币设置
□ 政策页面（退货政策、隐私政策、服务条款）

技术配置：
□ SSL证书激活
□ 域名绑定（独立域名，非*.myshopify.com）
□ 废弃购物车邮件设置
□ 结算流程优化（支持PayPal + Stripe + 信用卡）
```

### 3.2 产品上传规范

| 字段 | 填写建议 | 示例 |
|------|---------|------|
| Title | `{产品名} {型号} {规格}` | `Ergonomic Office Chair YC-200 with Mesh Back` |
| Description | 用途+规格+优势+MOQ | 详见内容模板 |
| Vendor | 品牌名或"N/A" | `YourBrand` |
| Product Type | 分类层级 | `Furniture > Office Chairs` |
| Tags | 核心关键词 | `office-chair, ergonomic, wholesale, B2B` |
| Images | 白底主图 + 场景图 | 至少3张，≥1000px |

### 3.3 B2B特殊配置

- **Wholesale渠道**：设置批发价（≥10%折扣）
- **最小起订量**：通过第三方App实现MOQ限制
- **自定义结算**：支持银行转账、TT付款
- **VIP客户分组**：设置专属价格和访问权限

## 四、多渠道获客最佳实践

### 4.1 渠道优先级矩阵

| 渠道 | 适合市场 | 成本 | 效果 | 启动周期 |
|------|---------|------|------|---------|
| Google SEO | 全球 | 低 | 慢（3-6月） | 长 |
| Facebook广告 | 欧美 | 中 | 快（1-2月） | 中 |
| LinkedIn | B2B高端 | 中 | 中 | 中 |
| WhatsApp营销 | 东南亚/中东 | 低 | 快 | 短 |
| TikTok | 年轻市场 | 低 | 快 | 短 |

### 4.2 获客内容策略

```
第一阶段（0-3月）：
- 每周发布2-3条产品内容
- 每周发布1-2条工厂/生产内容
- 每月2条客户案例

第二阶段（3-6月）：
- 开始投放Facebook广告（$500-1000/月测试）
- 建立WhatsApp客服号码
- 启动LinkedIn内容矩阵

第三阶段（6月+）：
- 数据驱动优化广告投放
- 启动邮件营销
- 开发转介绍计划
```

### 4.3 客户评分模型

使用多维度评分识别高价值客户：

| 维度 | 指标 | 权重 |
|------|------|------|
| 互动深度 | 邮件打开率、点击率 | 20% |
| 需求明确度 | 产品类型+数量+目标价 | 30% |
| 决策能力 | 公司规模、职位 | 20% |
| 跟进响应 | 响应速度、回合数 | 15% |
| 历史行为 | 复购、推荐 | 15% |

总分≥80分 → **A级客户**（24h内人工跟进）
总分≥50分 → **B级客户**（自动培育序列）
总分<50分 → **C级客户**（内容自动触达）

## 五、转化提升最佳实践

### 5.1 首次响应黄金3分钟

- 设置邮件自动规则（<5分钟触发回复确认）
- WhatsApp设置快速回复模板
- 独立站聊天窗口7×24h开启

### 5.2 询盘处理SOP

```
收到询盘 → 5分钟内发送确认邮件
    ↓
30分钟内完成客户背景调查
    ↓
2小时内发送初步报价
    ↓
标注客户意向等级（A/B/C）
    ↓
加入跟进序列（3/7/14/30天）
    ↓
高意向（A级）→ 主动电话/视频
```

### 5.3 转化率优化

- **落地页优化**：A/B测试CTA文案和按钮颜色
- **表单简化**：B2B询盘表单不超过5个字段
- **信任背书**：添加客户评价、认证证书
- **紧迫感营造**：库存数量、交期承诺

## 六、安全与合规

### 6.1 API密钥管理

- **禁止**在代码中硬编码密钥，使用环境变量
- WordPress App Password **不要**使用管理员账户
- Shopify Access Token 设置最小必要权限
- 定期轮换密钥（建议90天）

### 6.2 数据合规

- GDPR合规：欧盟用户数据需明确授权
- 网站隐私政策页面
- Cookie同意弹窗
- 数据保留期限（建议不超过2年）
