```
【分类】政策合规
【标签】#1039 #市场采购 #政策红利

【问题】
什么是1039市场采购贸易？和一般贸易有什么区别？

【答案】
【定义】1039是海关监管代码，指"市场采购贸易方式"，是义乌独有的外贸政策。

【核心优势】
| 对比项 | 1039市场采购 | 一般贸易(0110) |
|--------|-------------|----------------|
| 增值税 | 免征不退 | 免抵退 |
| 外汇 | 可合法收结汇 | 需发票核销 |
| 申报 | 按章归类简化 | 逐项申报 |
| 适用主体 | 个体工商户/小微企业 | 一般纳税人 |

【适用条件】
✅ 在义乌市场采购商品
✅ 单票货值<15万美元
✅ 委托有资质的外贸公司出口

【办理流程】
1. 注册义乌个体工商户
2. 办理市场采购贸易经营者备案
3. 开通外汇收结汇账户
4. 在Chinagoods平台注册

【关联】FAQ-002: 如何办理1039资质？
```

### FAQ-003：1039出口有哪些合规红线？

```
【分类】政策合规
【标签】#1039 #合规 #红线

【问题】
1039市场采购出口有哪些合规红线不能碰？

【答案】
【绝对红线】违者可能面临罚款、追责甚至刑事责任

❌ 低报货值（申报价格低于实际成交价70%）
❌ 虚假贸易（无真实货物或交易）
❌ 拆分结汇（将大额拆分为多笔规避监管）
❌ 地下钱庄换汇
❌ 出口非义乌市场商品
❌ 侵权产品/仿牌出口
❌ 禁限出口商品

【灰色地带】建议避免

⚠️ 买单出口（用他人名义报关）
⚠️ 循环出口（同一批货物反复出口骗税）
⚠️ 业务与注册主体不符

【正确做法】
✅ 贸易真实性：合同、发票、物流单证齐全
✅ 货值准确性：如实申报，不低于70%
✅ 收汇合规：通过银行正规结汇
✅ 单证留存：至少保存3年

```

【标签】#商贸城 #拿货 #议价

【问题】
在义乌商贸城拿货如何有效议价？

【议价原则】义乌档口利润薄，大额优惠需走量

| 数量 | 通常折扣 |

## 五、支付结算类 FAQ

### FAQ-030：T/T付款比例怎么定？

```
【分类】支付
【标签】#T/T #付款方式 #风控

【问题】
T/T电汇付款，30%+70%还是50%+50%更安全？

【答案】
【推荐结构】30%预付 + 70%见单

【付款结构对比】
| 结构 | 预付 | 风险 | 适用场景 |
|------|------|------|---------|
| 30%+70% | 低 | 适中 | 首选方案 |
| 50%+50% | 中 | 较低 | 大额订单 |
| 100%前T/T | 高 | 低 | 样品/小额 |

【安全操作流程】
```
签订合同 → 收到30%预付 → 开始备货
     ↓
备货完成 → 通知客户验货/发货
     ↓
客户付70%尾款 → 正本提单到手
     ↓
确认到账 → 通知货代放单
```

【关键原则】
① 预付款到账后才开始备货
② 正本提单在手，等尾款到账
③ 尾款到账后才通知放单
④ 水单≠到账，以银行实际入账为准

【关联】FAQ-031: 如何识别付款风险？
```

### FAQ-031：客户付款有哪些风险信号？

```
【分类】支付
【标签】#风控 #骗货 #危险信号

【问题】
如何识别客户付款中的风险信号？

【答案】
【高危信号清单】🚨 发现立即警惕

| 信号 | 风险描述 | 建议动作 |
|------|---------|---------|
| 成交太爽快 | "太好了，马上付款" | 核实身份 |
| 首单即大额 | 首次合作就下大单 | 提高预付比例 |
| 绕过平台 | 要求不走平台直接转账 | 拒绝 |
| 频繁催促 | 急着让你发货 | 确认付款到账 |
| 变更地址 | 不断更换收货地址 | 书面确认 |
| 拒绝视频 | 不愿意视频核实 | 谨慎合作 |
| 代付货款 | 用他人账户付款 | 核实原因 |
| 水单造假 | 发水单但未到账 | 以银行为准 |

【正确应对】
```
遇到高危信号 → 保持冷静 → 要求更多保障
     ↓
提高预付比例/购买出口信用保险
