## 一、评估框架总览

### 六大核心维度

```
供应商评估 = 产能评估 × 品质评估 × 价格评估 × 交期评估 × 配合度 × 稳定性
                      ↓
              综合评分 = 各维度加权平均
```

### 权重配置（可按需调整）

| 维度 | 权重 | 适用场景 |
|------|------|---------|
| 品质 | 30% | 高客单价/品牌客户 |
| 价格 | 25% | 成本敏感型业务 |
| 交期 | 20% | 急单/季节性产品 |
| 配合度 | 15% | 定制化需求多 |
| 产能/稳定性 | 10% | 大批量长期合作 |

## 五、图片找货SOP（遨虾功能Copy）

> 当无法实地考察时，通过图片快速匹配供应商

### 5.1 图片收集

```
【图片要求】
□ 产品正面图（清晰、无水印）
□ 产品侧面图
□ 产品细节图（材质/做工）
□ 包装图（如有）
□ 参考样品图（竞品图片也可）

【图片命名规范】
[品类]-[款号]-[日期]-[序号]
示例：bag-001-20260426-01.jpg
```

### 5.2 图片找货流程

```
Step 1: 图片标准化
├── 调整尺寸：800×800像素
├── 去除水印/背景
└── 标注关键特征

Step 2: 商贸城匹配
├── 一区：玩具、饰品、工艺品
├── 二区：箱包、五金、电子
├── 三区：文具、化妆品、眼镜
├── 四区：袜类、内衣、日用百货
└── 五区：进口商品、床品、纺织品

Step 3: 档口筛选
├── 第一轮：找相似款≥3家
├── 第二轮：询价对比
└── 第三轮：拿样验证

Step 4: 供应商建档
├── 录入评估系统
├── 打标签分类
└── 定期复评
```

### 5.3 图片找货沟通话术

```
档口沟通示例：

"老板你好，我看到你这款[产品]，我有一张图片，想看看你有没有类似款。
（展示图片）
这款做工看起来和你的差不多，价格怎么样？
100件什么价？1000件呢？
能先拿一个样品看看吗？"
```

## 六、供应商分级管理

### 6.1 分级标准

| 等级 | 综合评分 | 订单优先级 | 账期支持 | 定制服务 |
|------|---------|-----------|---------|---------|
| **A级（战略）** | 4.5+ | 优先排单 | 30-45天 | 深度定制 |
| **B级（核心）** | 4.0-4.4 | 正常排单 | 款到发货 | 基础定制 |
| **C级（备选）** | 3.5-3.9 | 按需下单 | 款到发货 | 标准品 |
| **D级（观察）** | 3.0-3.4 | 减少下单 | 款到发货 | 标准品 |
| **E级（淘汰）** | <3.0 | 停止合作 | — | — |

### 6.2 分级调整规则

```
【季度复评】
- 每季度末进行分级复评
- 根据历史合作数据调整分级
- 记录重大事件（延误/质量问题）

【动态升级】
- 连续3个月表现优秀 → 申请升级
- 紧急订单超预期完成 → 加分
- 主动配合新品开发 → 加分

【动态降级】
- 连续2次质量事故 → 降一级
- 一次严重延误 → 降一级
- 沟通态度恶劣 → 降一级
```

## 七、常见问题FAQ

**Q1: 如何快速判断供应商可靠性？**
```
1. 查从业年限：>3年为佳
2. 看档口位置：核心区>边缘区
3. 问客户案例：有无大客户合作
4. 试样品：质量是否稳定
5. 查口碑：同行评价如何
```

**Q2: 样品免费，但需要运费，合理吗？**
```
合理。义乌档口利润薄，免费样品+到付运费是常见模式。
建议：到付运费控制在30-50元以内可接受。
```

**Q3: 首单应该下多少量？**
```
建议：
- 常规产品：100-200件
- 定制产品：50-100件
- 大件/高价值：20-50件
- 季节性产品：先100件试销
```

**Q4: 供应商坐地起价怎么办？**
```
预防措施：
1. 书面锁定价格周期（建议≥30天）
2. 阶梯下单锁定优惠
3. 多家备选防止单一家依赖

应对策略：
1. 出示之前报价截图
2. 表明长期合作意愿换优惠
3. 考虑更换备选供应商
```
