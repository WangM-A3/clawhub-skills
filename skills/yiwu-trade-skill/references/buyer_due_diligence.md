## 四、Step 2: 数据验证

### 4.1 工商信息核验

```
【核验清单】
□ 公司全称是否与注册一致
□ 注册地址是否真实存在
□ 注册资本是否与业务规模匹配
□ 成立时间（>1年为佳，>3年为优）
□ 经营状态（存续/在业/注销）
□ 法人代表是否清晰
□ 股权结构是否清晰

【异常信号】
⚠️ 注册资本认缴制（未实缴）
⚠️ 注册地址为虚拟地址
⚠️ 频繁更换法人
⚠️ 经营异常记录
```

### 4.2 信用报告解读

**邓白氏评分体系**：

| 评分区间 | 风险等级 | 建议 |
|---------|---------|------|
| 75-100 | 低风险 | 可放心合作 |
| 50-74 | 中低风险 | 注意监控 |
| 20-49 | 中高风险 | 谨慎合作 |
| 1-19 | 高风险 | 不建议合作 |

**信用报告核心指标**：

```
□ 邓白氏评级 (DE Rating)
□ 付款指数 (Payment Index)
□ 财务实力评估 (Financial Strength)
□ 破产预测 (BPSR)
□ 营运状态评估 (Business Activity)
```

### 4.3 社交媒体验证

```
【LinkedIn验证】
□ 公司主页是否存在
□ 员工数量是否与描述一致
□ 近期动态是否正常更新
□ 联系人职位是否合理
□ 相互联系人的可信度

【Facebook/Instagram验证】
□ 主页关注人数（与业务规模匹配）
□ 帖子互动率（判断活跃度）
□ 客户评价（口碑参考）
□ 主页创建时间（判断运营年限）
```

## 五、Step 3: 风险评估

### 5.1 风险评估模型

```
综合风险指数 = 信用风险 × 30% + 经营风险 × 30% + 交易风险 × 40%
```

| 风险类型 | 评估维度 | 权重 |
|---------|---------|------|
| **信用风险** | 邓白氏评级/付款记录/历史纠纷 | 30% |
| **经营风险** | 经营年限/财务状况/市场地位 | 30% |
| **交易风险** | 订单规模/付款方式/沟通配合 | 40% |

### 5.2 风险信号清单

#### 🚨 一级风险信号（红线）

| 信号 | 风险描述 | 建议动作 |
|------|---------|---------|
| 拒绝提供公司信息 | 可疑客户 | 立即终止 |
| 要求发货到个人地址 | 疑似诈骗 | 立即终止 |
| 首单即大额(>$10万) | 高风险 | 拒绝或提至50%预付 |
| 要求100%赊销 | 高风险 | 拒绝 |
| 公司成立<6个月 | 新公司风险高 | 降低额度 |

#### ⚠️ 二级风险信号（黄线）

| 信号 | 风险描述 | 建议动作 |
|------|---------|---------|
| 要求超长账期(>60天) | 资金风险 | 缩短至30天内 |
| 频繁变更收货地址 | 可疑行为 | 要求书面确认 |
| 价格异常敏感 | 可能有诈 | 提高警惕 |
| 催促快速发货 | 可能想骗货 | 核实后再发 |
| 新注册公司(<1年) | 风险未知 | 小单试水 |

```

"您好，我是[姓名]，来自义乌[公司名]。我们收到了您的询盘，
想跟您确认一下贵公司的采购信息，以确保我们提供最合适的产品。"

【存疑】：回避问题、支支吾吾
```

## 九、常见问题FAQ

**Q1: 背调需要花多少钱？**
```
基础背调（免费）：
- Google搜索
- 天眼查基础信息
- LinkedIn查看

进阶背调（¥200-500）：
- 邓白氏信用报告
- 格兰德海关数据查询

深度背调（¥1000+）：
- 专业征信公司报告
- 实地考察
```

**Q2: 客户不愿意提供资料怎么办？**
```
应对策略：
1. 解释目的："这是为您找到最合适的产品"
2. 降低门槛："只需要公司名称和联系方式"
3. 对等交换："我们先给您发产品资料"
4. 逐步建立："首次小单合作，后续再深入了解"

【底线】：至少要有公司名称，可通过公开渠道验证
```

**Q3: 海关数据显示客户实力很强，但实际沟通感觉不对？**
```
多维度验证：
1. 海关数据可能滞后（采购规模已变化）
2. 公司规模大不代表付款及时
3. 需要结合邓白氏信用报告
4. 最终判断：综合评估，不依赖单一数据源
```

**Q4: 首单应该下多少量才安全？**
```
建议：
- 高风险客户：样品单
- 中风险客户：$1000-3000
- 低风险客户：正常订单
- 首次合作：不超过月产能的20%
```
