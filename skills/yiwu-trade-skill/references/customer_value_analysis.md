## 一、CLV客户终身价值计算

### 1.1 CLV定义与义乌场景适配

```
【基础定义】
CLV = 客户全生命周期内贡献的总利润

【义乌外贸特殊考量】
├── 客户流失率相对较高（市场波动敏感）
├── 单客户采购品类分散（多品类交叉销售机会）
├── 复购周期短（快消品/小商品特性）
└── 依赖关系维护（人情社会特性）
```

### 1.2 CLV计算公式

#### 基础版公式（单品类）

```
CLV = (年均采购额 × 平均毛利率 - 年均运营成本) × 平均客户生命周期(年)

示例计算：
├── 年均采购额：$50,000
├── 平均毛利率：20%
├── 年均运营成本（服务成本）：$2,000
├── 平均客户生命周期：3年

CLV = ($50,000 × 20% - $2,000) × 3
    = ($10,000 - $2,000) × 3
    = $8,000 × 3
    = $24,000
```

#### 进阶版公式（多品类/全链路）

```
CLV = Σ(品类i年均采购额 × 品类i毛利率) × 客户生命周期系数 × 关系维护系数 - 获客成本

参数说明：
├── 品类i年均采购额：客户在品类i的平均年采购金额
├── 品类i毛利率：不同品类毛利率可能有差异
├── 客户生命周期系数：基于流失风险调整（1.0为标准）
│   ├── 高风险客户：0.6-0.8
│   ├── 稳定客户：1.0
│   └── 忠诚客户：1.2-1.5
├── 关系维护系数：基于客户粘性调整（1.0为标准）
│   ├── 纯交易关系：0.8
│   ├── 稳定合作关系：1.0
│   └── 战略合作关系：1.2-1.5
└── 获客成本（CAC）：开发该客户的直接成本

示例计算（多品类）：
├── 家居品类：$30,000 × 18% = $5,400
├── 汽摩配品类：$20,000 × 22% = $4,400
├── 小商品品类：$15,000 × 25% = $3,750
├── 年均毛利贡献：$13,550
├── 年均运营成本：$3,000
├── 客户生命周期系数：1.2（稳定老客户）
├── 关系维护系数：1.0
└── 获客成本：$5,000（摊销）

CLV = ($13,550 - $3,000) × 1.2 × 1.0 - $5,000
    = $10,550 × 1.2 - $5,000
    = $12,660 - $5,000
    = $7,660
```

### 1.3 CLV分级标准（义乌外贸场景）

|---------|---------|----------|----------|
| **S级（战略客户）** | >$50,000 | 5% | 年采购>30万，多品类，战略合作 |
| **A级（核心客户）** | $20,000-$50,000 | 15% | 年采购10-30万，稳定复购 |

| **C级（培育客户）** | $1,000-$5,000 | 35% | 年采购1-3万，需要培育 |
| **D级（潜力客户）** | <$1,000 | 15% | 小额试单，转化中 |

## 二、RFM分层运营策略

### 2.1 RFM模型定义

| 维度 | 全称 | 义乌外贸场景定义 | 计算方式 |
|------|------|------------------|----------|
| **R** | Recency（最近购买） | 最近一次下单距今天数 | 天数越少越好 |
| **F** | Frequency（购买频次） | 近6个月下单次数 | 次数越多越好 |
| **M** | Monetary（购买金额） | 近6个月累计采购额 | 金额越高越好 |

### 2.2 RFM评分标准（义乌外贸适配）

```markdown

```

## 三、高价值客户识别标准

### 3.1 综合评分体系

```
高价值客户 = 交易价值 × 关系价值 × 战略价值

【交易价值】(权重40%)
├── CLV评分（20%）
├── RFM综合评分（10%）
└── 年采购额增长率（10%）

【关系价值】(权重30%)
├── 复购品类数（10%）
├── 合作时长（10%）
└── 转介绍能力（10%）

【战略价值】(权重30%)
├── 目标市场契合度（10%）
├── 品牌背书价值（10%）
└── 合作意愿度（10%）
```

### 4.3 各等级运营策略

#### D级客户（潜力客户）运营

```
目标：将D级转化为C级，首单客户→稳定复购客户

├── 首单体验：极致化（服务>客户预期）
├── 跟进频率：首单后7天/30天/60天主动联系
├── 品类引导：根据首单品类，推荐关联品类
└── 激励政策：复购享95折

关键指标：
├── 首单后30天复购率目标：≥30%
├── 60天转化C级率目标：≥20%
└── 首单客户流失率目标：<40%
```

#### C级客户（培育客户）运营

```
目标：将C级培育为B级，小客户→中等客户

策略重点：
├── 品类扩展：Cross-selling，每个季度推荐1个新品类
├── 采购激励：累计采购达$3,000享97折
├── 专属顾问：1对1服务，响应优先级
└── 新品首发：优先获得新品信息和样品

关键指标：
├── 年均品类增长：≥1个品类
├── 年采购增长率：≥30%
└── 年度留存率：≥70%
```

#### B级客户（成长客户）运营

```
目标：将B级升级为A级，稳定客户→核心客户

策略重点：
├── 客单价提升：推荐高毛利品类，优化产品组合
├── 频次优化：月度采购→周度采购
├── 关系深化：季度业务review，高层互动
└── 利润管理：引导升级服务，提升利润贡献

关键指标：
├── 客单价年增长：≥25%
├── 年采购额目标：达到$30,000
└── 客户满意度：≥90分
```

```

策略重点：

### 5.2 客户健康度评分卡

└── 订单准时率：权重11%

├── 沟通响应率：权重11%
├── 资料配合度：权重11%
└── 投诉/纠纷率：权重11%

【增长健康度】(33%)
├── 采购增长率：权重11%
├── 品类扩展数：权重11%
└── 复购频次：权重11%

健康度等级：
- 绿（80-100分）：健康，持续维护
- 黄（60-79分）：亚健康，重点关注
- 红（<60分）：预警，制定改善计划
```
