# 效果承诺机制

> 以义乌30年实战经验为背书，以可量化、可追踪、可兑现为原则，为客户提供"效果导向"的轻量化外贸服务承诺。

---

## 一、承诺边界定义

### ✅ 可承诺范围

| 承诺类型 | 具体指标 | 承诺标准 |
|----------|----------|----------|
| **合规交付** | 1039资质办理 | 15个工作日内完成备案 |
| **时效保障** | 首单出运周期 | 资料齐全后30天内完成首单 |
| **合规承诺** | 出口合规率 | 100%符合海关监管要求 |
| **收汇保障** | 资金安全率 | T/T分阶段付款模式下≥99% |
| **响应速度** | 询盘响应时间 | 工作时间2小时内回复 |
| **服务透明** | 订单可视化 | 全链路物流追踪覆盖 |

### ❌ 不可承诺范围

| 场景 | 原因 | 替代方案 |
|------|------|----------|
| 客户询盘转化率 | 受产品、市场、竞争等多因素影响 | 提供转化率提升培训和工具 |
| 具体订单金额 | 市场规模和客户决策不可控 | 提供GMV增长策略和路径 |
| 客户复购率 | 取决于客户自身经营状况 | 提供客户维护SOP和工具 |
| 特定国家清关时效 | 各国海关政策差异大 | 提供最优物流方案推荐 |
| 汇率锁定 | 金融市场不可预测 | 提供汇率风险管理建议 |

### 承诺豁免条款

以下情况导致无法兑现承诺时，不计入考核：

1. **不可抗力因素**：战争、自然灾害、疫情等
2. **政策突变**：海关政策、汇率管制等重大调整
3. **客户配合度不足**：资料提交延迟、决策周期过长
4. **第三方因素**：银行处理延迟、船公司延误等
5. **产品合规问题**：客户产品涉及知识产权或禁运

## 二、承诺指标定义

### 核心承诺指标体系

```
【合规承诺】
├── 1039资质办理通过率：100%
├── 报关单证合规率：100%
└── 收汇路径合规率：100%

【时效承诺】
├── 资质办理时效：15个工作日
├── 供应链响应时效：48小时（常规品）
├── 询盘响应时效：2小时（工作时间）
└── 首单出运周期：30个工作日

【质量承诺】
├── 源头质检覆盖率：100%
├── 出货抽检比例：5-10%
└── 不良品率控制：<3%

【服务承诺】
├── 客服在线时间：工作日8:00-20:00
├── 投诉响应时间：4小时
└── 问题解决时效：48小时
```

### 效果追踪指标

| 指标名称 | 计算公式 | 追踪频率 | 行业参考 |
|----------|----------|----------|----------|
| 询盘转化率 | 成交订单数/总询盘数 | 月度 | 5-15% |
| 样品成交率 | 成交订单数/样品单数 | 月度 | 20-40% |
| 客户回复率 | 有效回复数/总发送数 | 周度 | 10-30% |
| 首单复购率 | 90天内复购客户/首单客户 | 季度 | 25-40% |
| 客户留存率 | 期末客户数/期初客户数 | 季度 | 80-90% |

## 三、效果追踪方法

### 追踪体系架构

```
┌─────────────────────────────────────────────────────────┐
│                    效果追踪体系                           │
├─────────────────────────────────────────────────────────┤
│  客户层    │  订单层    │  服务层    │  财务层            │
│  ├─客户档案  │  ├─询盘记录  │  ├─响应时效  │  ├─收汇记录    │
│  ├─跟进日志  │  ├─报价记录  │  ├─服务满意度 │  ├─利润核算    │
│  └─价值评估  │  ├─订单状态  │  └─问题解决  │  └─成本分析    │
│             │  └─物流追踪  │            │               │
├─────────────────────────────────────────────────────────┤
│                    数据中台                              │
│         客户看板 + 订单看板 + 财务看板 + 运营看板         │
└─────────────────────────────────────────────────────────┘
```

### 追踪流程

```
1. 节点埋点
   └── 关键节点：资质备案完成 → 首单成交 → 首次回款 → 首次复购

2. 数据采集
   └── 客户行为数据 + 服务过程数据 + 经营结果数据

3. 定期报告
   └── 周报：服务时效、客户响应
   └── 月报：转化率、GMV、利润
   └── 季报：客户留存、CLV、复购率

4. 异常预警
   └── 询盘转化率 < 3%（预警）
   └── 客户30天无跟进（预警）
   └── 回款逾期 > 7天（预警）
```

### 追踪工具矩阵

| 工具类型 | 推荐方案 | 适用场景 |
|----------|----------|----------|
| 客户管理 | 微信标签+表格 / 简道云 | 中小规模客户管理 |
| 订单管理 | Excel / Chinagoods | 订单全流程追踪 |
| 物流追踪 | 17track / 货代系统 | 全链路物流可视化 |
| 财务管理 | 财务软件 / 银行流水 | 收汇、结汇、利润核算 |
| 数据看板 | BI工具 / 简道云 | 多维度经营分析 |

## 四、未达标补偿机制

### 补偿触发条件

| 承诺类型 | 触发条件 | 补偿标准 |
|----------|----------|----------|
| 1039资质办理 | 超15个工作日未完成 | 退还代操作费 |
| 首单出运周期 | 超30个工作日（客户原因除外） | 退还服务费×50% |
| 询盘响应时效 | 月度响应达标率 < 95% | 赠送1次增值服务 |
| 报关合规率 | 出现海关查验（非瞒报导致） | 协助处理+费用补贴 |

### 补偿申请流程

```
申请条件确认 → 提交申请表单 → 48小时审核 → 补偿执行 → 结果反馈
      │              │              │            │            │
      ▼              ▼              ▼            ▼            ▼
   是否触发    填写原因+证据    核实承诺记录   补偿方案确定   记录存档
```

### 补偿方式

| 补偿类型 | 适用场景 | 操作方式 |
|----------|----------|----------|
| 费用减免 | 服务费退还 | 抵扣下期服务 |
| 增值服务 | 培训/咨询赠送 | 预约安排 |
| 资源优先 | 供应链/物流优先 | 绿色通道 |
| 现金补偿 | 直接经济损失 | 对公转账 |

## 五、承诺话术模板

### 承诺类话术

#### 初次接触承诺

```
"我们承诺：
✅ 合规交付 - 1039资质15个工作日办结
✅ 时效保障 - 资料齐全后30天完成首单
✅ 资金安全 - T/T分阶段付款，零风险收汇
✅ 响应速度 - 工作时间2小时必回复

如有延迟，我们承担相应责任。"
```

#### 效果承诺说明

```
"需要说明的是，外贸业务涉及多个环节，我们能承诺的是：
1. 我们能控制的：合规、时效、服务质量
2. 需要共同参与的：产品选择、市场开拓、客户沟通
3. 客观因素影响的：海关政策、汇率波动、市场竞争

我们提供的是"能力承诺"+"路径指导"+"工具支撑"，效果取决于多方配合。"
```

#### 转化率预期管理

```
"基于我们服务过的客户数据：
- 优秀水平（top 20%）：询盘转化率 > 15%
- 中等水平（平均）：询盘转化率 5-10%
- 新手起步：询盘转化率 3-5%

影响转化的关键因素：
1. 产品竞争力（40%权重）
2. 客户匹配度（30%权重）
3. 跟进响应速度（20%权重）
4. 服务专业度（10%权重）

我们负责后两项的提升，前两项需要您的产品和市场判断。"
```

### 承诺边界话术

#### 婉拒不合理承诺请求

```
"非常理解您希望看到明确的效果承诺。关于这一点，我们的原则是：

❌ 我们不做虚假承诺
❌ 我们不承诺无法控制的指标

✅ 我们承诺的是服务质量
✅ 我们承诺的是合规保障
✅ 我们承诺的是时效兑现

建议我们把关注点放在：
→ 如何提升产品竞争力
→ 如何提高客户沟通效率
→ 如何优化供应链成本

这些是我们可以一起努力的方向，您觉得呢？"
```

#### 豁免条款说明

```
"以下情况导致的延误，不在我们的承诺范围内：
1. 资料不全或客户延迟决策
2. 海关政策突变或银行处理延迟
3. 不可抗力因素（自然灾害等）
4. 产品涉及知识产权争议

如遇以上情况，我们会第一时间沟通解决方案。"
```

### 续费/增值服务话术

```
"基于过去X个月的数据：
📊 您的转化率：X%
📈 复购率：X%
💰 CLV（客户终身价值）：X元

续费服务将包含：
- 优先响应通道
- 专属供应链对接
- 每月1次策略复盘
- 新市场拓展支持

预计持续合作12个月，您的CLV可达XX元，是当前投入的X倍。"
```

## 六、承诺体系运作机制

### 承诺兑现保障

```
【事前】
├── 承诺标准化：明确承诺范围、指标、期限
├── 风险告知：提前说明不可控因素
└── 客户确认：双方签署服务协议

【事中】
├── 节点追踪：关键节点及时反馈
├── 预警机制：延期风险提前预警
└── 主动沟通：问题出现主动说明

【事后】
├── 结果复盘：承诺达成情况分析
├── 补偿兑现：未达标按约补偿
└── 持续优化：机制迭代升级
```

### 承诺升级路径

| 合作阶段 | 承诺层级 | 配套服务 |
|----------|----------|----------|
| 初次合作（0-3个月） | 基础承诺 | 标准服务流程 |
| 信任建立（3-6个月） | 进阶承诺 | 专属顾问对接 |
| 深度合作（6-12个月） | 高级承诺 | 战略级服务 |
| 长期合作（12个月+） | 定制承诺 | 全面托管服务 |
