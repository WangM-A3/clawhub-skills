## 一、为什么需要精准触达决策人？

```
传统开发信 → 命中率低（90%到不了决策人）
精准触达   → 命中率高（直接对话关键人）
```

```

【痛点确认】

【证据支持】
"比如[某客户]，3个月后[具体结果]"
```

### 6.1 LinkedIn职位识别表

| 关键词 | 职位层级 | 开发优先级 | 话术重点 |
|-------|---------|-----------|---------|
| Founder, CEO, Managing Director, Owner | 决策层 | ⭐⭐⭐ | 战略价值 |
| Procurement Head, Purchasing Director, VP of Sourcing | 采购总监 | ⭐⭐⭐ | 成本优化 |
| Buyer, Sourcing Manager, Merchandiser | 执行层 | ⭐⭐⭐⭐ | 产品匹配 |
| Quality Manager, Warehouse Manager | 配合层 | ⭐⭐ | 验货物流 |

### 6.2 快速识别四步法

```
Step 1: 查看LinkedIn"People also viewed"
        → 找到组织架构

Step 2: 查看"About"页面描述
        → 了解采购流程

Step 3: 查看帖子评论者
        → 找到活跃的采购人员

Step 4: 查看公司员工数量
        → 100人以下：CEO直接决策
        → 100-500人：采购经理主导
        → 500+：Buyer执行，经理审批
```

## 八、常见问题

**Q1: 找不到决策人联系方式怎么办？**
```
替代方案：
1. LinkedIn发送connection request
2. 找到采购部门公共邮箱（info@/sales@）
3. 通过展会/行业活动认识
4. 通过同行引荐
5. 发general邮件请对方转达
```

**Q2: 决策人回复冷淡怎么办？**
```
分析原因：
1. 开发信太泛 → 更加个性化
2. 时机不对 → 调整跟进节奏
3. 价值不清晰 → 强化价值主张
4. 已有供应商 → 强调差异化

策略：
- 提供免费样品/报告吸引
- 找到他的痛点针对性解决
- 保持联系，等待时机
```

**Q3: 如何判断决策人是否真实？**
```
验证方法：
1. LinkedIn主页完整度
2. 公司官网是否列出此人
3. 行业展会/论坛是否有此人
4. 共同联系人确认
5. 公司规模与职位是否匹配
```
